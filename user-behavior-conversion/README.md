# 淘宝用户行为分析

用 2017-11-25 到 2017-12-03 的淘宝用户行为数据，定位浏览到购买的转化漏点，拆人群和商品，给出三条策略假设和回测结果。

## 业务问题

整体转化率看起来正常，但高点击人群、加购人群和高流量商品里都有异常。问题不是用户完全不买，而是流量和商品结构不匹配。分析要回答三件事：

- 转化漏点在哪个人群、哪类商品
- 这些漏点各占多少用户和流量
- 给什么动作，怎么回测

## 数据

- 来源：阿里天池淘宝用户行为数据集（UserBehavior），[数据集地址](https://tianchi.aliyun.com/dataset/649)
- 窗口：2017-11-25 ~ 2017-12-03，9 天，剔除 11-24 不完整数据
- 规模：约 1.0 亿行，98.8 万用户，450 万商品，9,405 个类目
- 字段：`user_id`、`item_id`、`category_id`、`behavior_type`、`timestamp`
- 行为：`pv`、`buy`、`cart`、`fav`
- 原始 CSV 约 3.6GB

## 分析链路

| 层 | 文件 | 内容 |
|:--|:--|:--|
| ODS | `hsql/ods.sql` | 原始 CSV 入 Hive |
| DWD | `hsql/dwd.sql` | 时间窗过滤、去重、非法 ID 过滤 |
| DWS | `hsql/dws.sql` | 用户、商品、类目粒度聚合 |
| ADS | `hsql/ads.sql` | 六张报表结果表 |

ADS 六张表：`ads_overall_conversion`、`ads_daily_trend`、`ads_user_segment`、`ads_item_high_traffic`、`ads_recommend_list`、`ads_recommend_effect`。

## 关键结果

| 指标 | 结果 |
|:--|:--|
| 整体 pv→buy 转化率 | 2.25% |
| 购买用户渗透率 | 68.3% |
| 高点击低购买人群 | 4.94 万人，buy_rate 0.51%，占 pv 13.72% |
| 高意向未成交人群 | 25.60 万人，占 25.9% |
| 高流量低转化商品 | 59.7 万个，占 pv 61.4% |
| 推荐名单回测 | 46.28 万对用户商品，buy/pv 1.97% |

整体 pv→buy 只有 2.25%，但 68.3% 的浏览用户窗口内买过。转化率低主要是人均浏览次数多，行为转化率被拉低。真正的漏点在两处：高点击低购买人群的 buy_rate 只有 0.51%，低于全站 2.25%；高流量低转化商品占了 61.4% 的 pv，但转化低于窗口均值。

## 策略

| 策略 | 对象 | 动作 | 度量 |
|:--|:--|:--|:--|
| S1 品类推荐 | 高点击低购买人群 | 按历史类目转化给每个用户推 Top3 商品 | 推荐商品 buy/pv、名单曝光覆盖率 |
| S2 优惠券 | 高意向未成交人群 | 对加购或收藏但窗口内没下单的人发券 | 加购后购买率 |
| S3 商品降权 | 高流量低转化商品 | 按类目批量降低资源投入，把流量让给高转化商品 | 该批商品曝光率、cart/fav→buy |

## 口径

- M0：`sum(buy) / sum(pv)`，按行为次数
- M1：购买用户数 / 浏览用户数，按 `user_id` 去重
- 人群和商品分层阈值用分位数计算，不写死固定值
- 所有对比统一用全站均值做基准

完整字段和公式见 [ads_fields.md](./doc/ads_fields.md)，分析思路见 [分析思路.md](./doc/分析思路.md)。
